Azure Functions + Durable Functions - Feynman Way of Understanding

Start from the failure problem: work can last for hours or days, machines restart, steps run in parallel, and some steps must wait. Rebuild Durable Functions from that constraint.

integration path

Client / EHR → APIM → Logic Apps → Service Bus → Azure Functions. This section starts exactly where the Messaging notes stopped: the message is durable; now the consumer must process it safely.

core distinction

Plain Function: execute one bounded unit of work. Durable Functions: coordinate many units with persisted progress, timers, external events, retries, and recovery.
